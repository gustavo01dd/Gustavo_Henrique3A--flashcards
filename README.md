# flashcards-com-HTML-e-CSS

Projeto de flashcards de **mito ou verdade** — mitos e verdades da tecnologia.

Feito por **Gustavo Henrique – 3A**.

## Como usar
1. Abra o arquivo `index.html` no navegador.
2. Clique (ou use a tecla Enter) em um cartão para virar e ver a resposta.
3. Use os botões para **embaralhar** os cartões ou **desvirar todos**.

## Arquivos
- `index.html` – estrutura da página
- `estilos.css` – cores, layout e animação de virada
- `script.js` – cria os cartões, vira, embaralha e conta quantos foram virados

## Tecnologias
HTML, CSS e JavaScript (sem bibliotecas).
